# 08. 테스트 · 검증 계획

> 1차는 시연 안정성 검증이 목적. V1 단계별 수용 기준(P0~P8)에 **V2 단계(V2-1~V2-9)** 를 더한다.
> 단계별 수용 기준과 원칙 준수 체크리스트를 둔다.

## 2. 검증 절차 (end-to-end, V2)

1. `streamlit run app/Home.py` 실행, 4단계 흐름 스텝퍼·Safe AI 패널 확인.
2. 우리반 설정: 클래스·유아(가명) 등록, 얼굴매칭 동의 토글(기본 OFF) 확인.
3. 매일 업로드 → **업로드 즉시 자동 분석**·진행률·상태 확인, 실패 시 재시도. 후보 누적 확인.
4. 수집 균형 매트릭스에서 유아×영역 카운트·부족 영역 확인.
5. (동의 ON) 얼굴 매칭 후보가 제시되고 교사 확정 전 미반영임을 확인.
6. 주간 초안 생성(기간·대상) → 대표 클립 1~3 표시 → 채택/수정/기각 → 확정(`final_record` 주차 메타) 확인.
7. AI비서가 검색/수정보조/촬영제안만 수행하고 기록됨을 확인.
8. 리포트에서 지원도 지표 확인, export 산출물에 미디어 경로가 없음을 확인.
9. 영상·얼굴 참조사진 접근/삭제/동의 변경이 `audit_log`에 남고, 외부 전송 페이로드에 원본 영상·참조사진·임베딩이 없음을 확인.

## 3. 원칙 준수 체크리스트 (릴리스 전 필수)

- [ ] 영상 중심 분석, 오디오는 보조에만 사용. 사진/음성은 1차 기록 수단 아님.
- [ ] AI는 후보·초안만 제시(자동 확정 없음), 교사 확정 단계 존재.
- [ ] 유아는 임시 ID + 얼굴 매칭 **후보**까지만, 확정은 교사(자동 신원 확정 없음). 얼굴 매칭 기본 OFF·동의 시 ON.
- [ ] 교사가 매일 개별 후보를 검토하지 않고, 주기적(1~2주)으로 확정.
- [ ] 누리 5영역 1차 분류 + KICCE 문항 후보(핵심) 제시.
- [ ] **관찰수준 점수·발달 점수·평정 점수 미산출.**
- [ ] 유아 실명 미저장, 얼굴 참조사진·임베딩을 실명과 결합하지 않음.
- [ ] 외부 전송은 선별 프레임/클립 + 텍스트로 한정. **원본 영상·얼굴 참조사진·임베딩 미전송.**
- [ ] export 산출물에 영상/프레임/클립/참조사진 **경로 없음.**
- [ ] 그래프 투영(사용 시)에 민감정보(실명·얼굴·경로) 없음. Neo4j 미사용.
- [ ] 영상·얼굴 참조사진 접근/삭제/동의 변경/초안 생성/AI비서 호출 감사 로그 동작, 비밀값은 `.env`(git 제외).

## 4. 테스트 데이터

- 실제 스마트안경 또는 **유사 시점으로 촬영한 샘플 영상**(IRB·동의 범위 내), 1~2주 누적 시연용 다회 분량.
- 얼굴 매칭 테스트는 **동의 처리된 가명 유아 참조사진**으로만 수행.
- 민감 데이터(영상·프레임·클립·얼굴 참조사진·임베딩·DB)는 저장소에 커밋하지 않는다(`data/`는 git 제외).

## 5. 테스트 종류 (구현 단계에서 추가)

- 단위: 프레임 추출·품질 필터·매핑 규칙·스키마 검증.
- 통합: 파이프라인 단계 연결(모의 비전 어댑터로 외부 호출 대체).
- 시연 리허설: P8에서 전체 흐름·소요 시간·비용 측정.

> 본 문서는 문서화 단계의 계획이며, 실제 테스트 코드는 이후 개발 단계에서 작성한다.
