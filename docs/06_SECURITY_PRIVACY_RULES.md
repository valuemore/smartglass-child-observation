# 06. 보안 · 개인정보 보호 규칙

> 유아 영상은 민감한 개인정보다. 본 문서의 규칙은 전 개발 단계에서 **강제**된다.

## 1. 핵심 원칙

1. **제한 접근**: 원본 영상·근거 클립·**얼굴 참조사진**은 `data/videos/`·`data/clips/`·`data/faces/` 제한 접근 디렉토리에만 저장하고 git에서 제외한다. 얼굴 임베딩은 로컬 DB에만 둔다.
2. **접근 로그**: 영상·**얼굴 참조사진**의 업로드·접근·분석·**얼굴 매칭**·**동의 변경**·**초안 생성**·**AI비서 호출**·export·삭제를 모두 `audit_log`/`ai_assistant_log`에 기록한다(누가·언제·무엇).
3. **삭제 정책**: 보관 기한 경과 또는 요청 시 영상·프레임·클립·STT·**얼굴 참조사진·임베딩·매칭 후보**·파생 데이터를 삭제하고 삭제 사실을 로그로 남긴다.
4. **외부 전송 최소화**: 외부 AI API에는 **선별 프레임/클립 + 필요한 텍스트만** 전송한다. **원본 영상 전체·얼굴 참조사진·얼굴 임베딩은 절대 전송하지 않는다.**
5. **비밀값 관리**: API 키 등은 `.env`로 주입하고 git에서 제외한다. 코드 하드코딩 금지.
6. **자동 식별·확정 금지**: AI는 유아를 자동 식별·확정하지 않는다. `child_A/B` 임시 ID + **얼굴 매칭 후보**까지만 제시하고 확정은 교사. 얼굴 매칭은 **기본 OFF·연구 동의 시 ON**.
7. **실명 미저장**: 유아 실명을 저장하지 않으며, 얼굴 참조사진·임베딩을 실명과 결합하지 않는다(가명 ID에만 연결).
8. **점수 금지**: 관찰수준·발달·평정 점수를 산출·저장하지 않는다. KICCE는 후보·근거 연결용.

## 2. 데이터 분류와 취급

| 데이터 | 민감도 | 저장 위치 | 외부 전송 |
|--------|--------|-----------|-----------|
| 원본 영상 | 높음 | `data/videos/` (제한 접근) | 금지 |
| 추출 프레임 | 높음 | `data/frames/` | **선별분만** 전송 가능 |
| 근거 클립 | 높음 | `data/clips/` (제한 접근) | **선별분만** 전송 가능 |
| **얼굴 참조사진** | 높음 | `data/faces/` (제한 접근, 동의 시) | **금지** |
| **얼굴 임베딩** | 높음 | DB(`child.face_embedding`, 로컬 전용, 동의 시) | **금지** |
| STT 전사 | 중간 | DB(`audio_segment`) | 해당 구간만 보조 동봉 |
| 관찰 후보/주간 초안/확정 기록 | 중간 | DB | 미전송(로컬 보관) |
| 얼굴 매칭 후보 | 높음 | DB(`face_match_candidate`) | 미전송 |
| 가명 ID 매칭표 | 높음 | DB(`child_match`) | 미전송 |
| API 키 | 높음 | `.env` | — |

- 실명은 저장하지 않는다. 교사가 부여하는 **가명 ID**만 사용한다.
- 얼굴 참조사진·임베딩은 `face_match_consent=1`일 때만 저장하고, **가명 ID에만** 연결한다.
- **그래프 투영(분석용)에는** 실명·얼굴 사진·임베딩·영상/클립 경로를 두지 않는다(id·텍스트 요약만).

## 3. 감사 로그(`audit_log` / `ai_assistant_log`)

- 기록 액션: `upload`, `access`, `analyze`, `export`, `delete`, **`face_match`, `reference_photo_access`, `face_consent_change`, `draft_generate`, `ai_assist`**.
- 필드: 행위자(actor), 액션, 대상 video_id(얼굴/비서는 nullable), 상세(detail), 시각(created_at).
- AI비서 상호작용은 `ai_assistant_log`(intent: search/edit_assist/shoot_suggest)에 별도 기록.
- UI는 영상·얼굴 참조사진 열람 시 "접근이 기록됨"을 표시한다.

## 4. 삭제 정책

- `video.retention_until` 경과 시 삭제 대상으로 표시.
- 영상 삭제 시 영상 파일 + 프레임/클립 파일 + 관련 DB 행(파생 포함)을 제거하고 `delete` 감사 로그 기록.
- **유아·클래스 삭제 시** 얼굴 참조사진·임베딩·얼굴 매칭 후보·매칭표를 연쇄 삭제하고 기록.
- **동의 철회 시** 해당 유아의 참조사진·임베딩을 즉시 삭제하고 `face_consent_change` 기록(가명 ID·텍스트 후보는 유지 가능).
- 교사/연구자는 UI에서 즉시 삭제를 요청할 수 있다.

## 5. 외부 API 전송 가드

- 전송 페이로드 구성 시 **원본 영상 경로/바이트·얼굴 참조사진·얼굴 임베딩이 포함되지 않음**을 코드 레벨에서 보장.
- 전송 대상은 프레임 이미지(또는 그리드/짧은 클립)와 해당 구간 텍스트로 한정.
- 얼굴 매칭은 **로컬 임베딩 비교만**으로 수행(외부 호출 없음).
- 비용 상한(프레임 수) 초과 시 전송을 차단한다.
- **export 가드**: JSON/CSV export에 영상·프레임·클립·참조사진 **경로 필드를 제외**(화이트리스트 직렬화).

## 6. 연구 윤리(IRB) 고려

- 영상 수집·활용은 기관 IRB 승인 및 보호자 동의 범위 내에서만 수행.
- **얼굴 참조사진·임베딩 활용은 별도 동의**를 받고, 동의 범위에서만 매칭을 ON 한다(기본 OFF).
- 데이터 보관 기한·삭제 절차를 동의 내용과 일치시킨다.
- 발표/논문용 산출물에는 식별 가능한 영상·이미지 노출을 피하고 가명 처리한다.

## 7. 개발 시 금지 사항 (재확인)

- 원본 영상·얼굴 참조사진·얼굴 임베딩 외부 전송 코드 작성 금지.
- 유아 자동 신원 확정/얼굴 인식 **신원화** 금지(매칭은 후보까지, 확정은 교사).
- 유아 실명 저장·실명-얼굴 결합 금지.
- 관찰수준·발달·평정 점수 산출 금지.
- 그래프 레이어(투영 포함)에 민감정보(실명·얼굴·경로) 저장 금지.
- export에 미디어 경로 노출 금지.
- AI비서가 신규 후보 자동 생성·확정·점수화하는 경로 금지.
- 비밀값 하드코딩 금지.
- 감사 로그 없이 영상·얼굴 참조사진에 접근·삭제하는 경로 금지.
