# 01. 프로젝트 브리프

## 1. 연구 배경

어린이집 교사는 일과 중 다수 유아를 동시에 돌보면서 관찰기록을 작성해야 하므로,
관찰과 기록을 병행하기 어렵고 기록의 일관성·근거 확보가 쉽지 않다.

본 연구는 교사가 착용한 **스마트안경으로 촬영한 교사 시점(1인칭) 영상**을 활용해,
AI가 유아 행동 관찰기록의 **초안(후보)** 을 생성하고 교사가 이를 검토·확정하는
워크플로를 제안·검증한다.

## 2. 스마트안경을 채택하는 이유

- **교사 시점 확보**: 교사가 실제로 바라보는 장면(유아의 행동, 또래 상호작용, 자료 사용)을 그대로 기록.
- **자연스러운 관찰**: 고정 카메라와 달리 교사의 시선·이동을 따라가므로 맥락이 풍부함.
- **기록 부담 경감**: 관찰 순간을 영상으로 남기고, 기록 작성은 사후에 AI 보조로 수행.

따라서 AI 분석의 **중심은 영상**이며, 오디오(발화)는 보조 증거로만 활용한다.

## 3. 목표

| 구분 | 내용 |
|------|------|
| 1차 (시연) | 학회 발표용. 샘플 영상 업로드 → 배치 분석 → 교사 검토 → 확정의 전체 흐름 시연 |
| 2차 (논문) | 프로토타입. AI 후보 대비 교사 확정 비교(채택률·수정률 등) 등 유효성 지표 산출 |

## 4. 범위 (In Scope)

- 녹화된 교사 시점 영상 **업로드 후 배치 분석**.
- 장면 분할 → 프레임 추출 → 비전 모델 분석 → 관찰 후보 생성.
- 누리과정 5영역 1차 분류 + **KICCE 유아관찰척도 60문항 후보 매핑(핵심)**.
- 오디오 STT를 **보조 근거**로 활용.
- 교사 검토 화면(`child_A/B` ↔ 가명 ID 매칭, 후보 채택/수정/기각/확정).
- 연구자 리포트(영역 분포, 문항 커버리지, AI 후보 vs 교사 확정 비교).
- 영상 제한 접근·감사 로그·삭제 정책.

## 5. 비범위 (Out of Scope)

- 실시간 스트리밍 분석 (1차 미포함).
- 유아 자동(확정) 식별·얼굴 인식 기반 신원 확정.
- 관찰수준 **점수 산출**.
- 오디오 전사 중심 분석.
- Neo4j 등 그래프 DB.
- 모바일 앱, 다국어 지원.

## 6. 이해관계자

- **교사(주 사용자)**: 영상 업로드, child 매칭, 관찰기록 검토·수정·확정.
- **연구자**: 리포트 열람, AI-교사 비교 지표 분석, 데이터 export.
- **유아/보호자(정보주체)**: 개인정보 보호 대상. 제한 접근·삭제 정책의 보호를 받음.

## 7. 용어 정의

| 용어 | 정의 |
|------|------|
| 교사 시점 영상 | 스마트안경으로 촬영한 1인칭 관찰 영상 |
| 장면(segment) | 콘텐츠 기반 장면 분할로 나뉜 시간 구간 |
| 프레임(frame) | 장면에서 추출한 정지 이미지 |
| 관찰 후보(observation candidate) | AI가 제시한, 확정되지 않은 관찰기록 초안 |
| temp_child_id | AI가 부여한 임시 유아 ID(`child_A`, `child_B` …) |
| 가명 ID | 교사가 매칭하는 실제 유아의 가명 식별자 |
| 누리과정 5영역 | 신체운동·건강 / 의사소통 / 사회관계 / 예술경험 / 자연탐구 |
| KICCE 유아관찰척도 | 본 시스템의 핵심 매핑 대상 관찰 척도(60문항) |
| 확정 기록(final record) | 교사가 검토·수정 후 확정한 관찰기록 |

## 8. 성공 기준 (1차 시연)

- 샘플 영상 1~2개로 업로드→분석→검토→확정→리포트 전 흐름이 끊김 없이 시연됨.
- 관찰 후보가 누리 영역·KICCE 문항 후보와 함께 근거를 포함해 제시됨.
- 교사가 child 매칭 및 후보 채택/수정/기각으로 관찰기록을 확정할 수 있음.
- AI가 어떤 기록도 자동 확정하지 않으며, 점수를 산출하지 않음이 확인됨.
