# 01. 프로젝트 브리프

## 1. 연구 배경

어린이집 교사는 일과 중 다수 유아를 동시에 돌보면서 관찰기록을 작성해야 하므로,
관찰과 기록을 병행하기 어렵고 기록의 일관성·근거 확보가 쉽지 않다.

본 연구는 교사가 착용한 **스마트안경으로 촬영한 교사 시점(1인칭) 영상**을 **매일 업로드·자동 분석**해
AI가 유아 행동 관찰기록의 **초안(후보)** 을 **누적**하고, 교사가 **수집 현황을 수시 확인**한 뒤
**1~2주 주기로 검토·확정**하는 **상시 현장 검증형** 워크플로를 제안·검증한다.

## 2. 스마트안경을 채택하는 이유

- **교사 시점 확보**: 교사가 실제로 바라보는 장면(유아의 행동, 또래 상호작용, 자료 사용)을 그대로 기록.
- **자연스러운 관찰**: 고정 카메라와 달리 교사의 시선·이동을 따라가므로 맥락이 풍부함.
- **기록 부담 경감**: 관찰 순간을 영상으로 남기고, 기록 작성은 사후에 AI 보조로 수행.

따라서 AI 분석의 **중심은 영상**이며, 오디오(발화)는 보조 증거로만 활용한다.

## 3. 목표

| 구분 | 내용 |
|------|------|
| 1차 (시연) | 학회 발표용. **1~2주 누적** → 수집 현황 확인 → **주간 초안 생성·확정** → 지원도 지표의 전체 흐름 시연 |
| 2차 (논문) | 프로토타입. AI 후보 대비 교사 확정 비교(채택률·수정률 등) 등 유효성 지표 산출 |

## 4. 범위 (In Scope)

- **클래스·유아 사전 등록**(가명 ID + 얼굴 참조사진, 동의 기반).
- 녹화된 교사 시점 영상 **매일 업로드 + 업로드 즉시 자동 분석·후보 누적**.
- 장면 분할 → 프레임 추출 → **근거 클립 추출** → 비전 모델 분석 → 관찰 후보 생성.
- **얼굴 참조 매칭 후보**(검출 얼굴 ↔ 등록 참조사진, 후보 + 신뢰도, 교사 확정).
- 누리과정 5영역 1차 분류 + **KICCE 유아관찰척도 59문항 후보 매핑(핵심)**.
- 오디오 STT를 **보조 근거**로 활용.
- **유아별·누리영역별 수집 현황 대시보드**(부족 영역 보완 안내).
- **주간/격주 관찰기록 초안** 생성 → 교사 검토 화면(매칭 확정, 후보 채택/수정/기각, 대표 근거 클립).
- **AI비서(제한형)**: 기록 검색·초안 수정 보조·보완 촬영 제안.
- 연구자 리포트(영역 분포, 문항 커버리지, AI **지원도** 지표).
- 영상·얼굴 참조사진·임베딩 제한 접근·감사 로그·삭제 정책.

## 5. 비범위 (Out of Scope)

- 실시간 스트리밍 분석 (미포함).
- 유아 **자동(확정) 식별**·얼굴 인식 **기반 신원 확정**(매칭은 후보까지, 확정은 교사).
- 관찰수준 **점수·발달 점수·평정 점수 산출**.
- 사진·음성을 **1차 기록 수단**으로 수집(영상 중심 원칙). 오디오는 보조만.
- 자유 형식 자동 태그, 성장 점수·발달 곡선 그래프.
- AI비서의 신규 관찰기록 자동 생성·확정.
- Neo4j 등 그래프 DB(분석은 SQLite 파생 인메모리 투영으로 한정).
- 클라우드 동기화·외부 공유, 모바일 앱, 다국어 지원.

## 6. 이해관계자

- **교사(주 사용자)**: 클래스·유아 등록, 매일 영상 업로드, 수집 현황 확인, 주간 초안 검토·수정·확정.
- **연구자**: 리포트 열람, AI **지원도** 지표 분석, 데이터 export(미디어 경로 제외).
- **유아/보호자(정보주체)**: 개인정보 보호 대상. 제한 접근·삭제 정책의 보호를 받으며, 얼굴 매칭은 **동의 범위 내**에서만 수행.

## 7. 용어 정의

| 용어 | 정의 |
|------|------|
| 교사 시점 영상 | 스마트안경으로 촬영한 1인칭 관찰 영상 |
| 장면(segment) | 콘텐츠 기반 장면 분할로 나뉜 시간 구간 |
| 프레임(frame) | 장면에서 추출한 정지 이미지 |
| 관찰 후보(observation candidate) | AI가 제시한, 확정되지 않은 관찰기록 초안 |
| temp_child_id | AI가 부여한 임시 유아 ID(`child_A`, `child_B` …) |
| 가명 ID | 교사가 등록·확정하는 실제 유아의 가명 식별자 |
| 클래스(class) | 교사가 등록하는 학급 단위. 유아·영상이 소속됨 |
| 유아(child) | 가명 ID·표시 라벨·(동의 시) 얼굴 참조사진을 가진 등록 유아. **실명 미저장** |
| 얼굴 참조사진/임베딩 | 등록 유아 식별용 사진 및 그 벡터. **로컬 전용·전송 금지**, 동의 기반 |
| 얼굴 매칭 후보 | 검출 얼굴 ↔ 등록 참조사진 유사도 기반 가명 매칭 후보(+신뢰도). 교사 확정 |
| 수집 현황 | 유아별·누리영역별 관찰자료 누적량·최근 관찰일·부족 영역 |
| 주간 관찰 초안(weekly draft) | 1~2주 누적 후보를 유아·영역별로 묶은 관찰기록 초안(후보) |
| 지원도 지표 | AI 후보가 교사 기록 작성을 얼마나 도왔는지(채택률·수정률·커버리지 기여) |
| 누리과정 5영역 | 신체운동·건강 / 의사소통 / 사회관계 / 예술경험 / 자연탐구 |
| KICCE 유아관찰척도 | 본 시스템의 핵심 매핑 대상 관찰 척도(59문항) |
| 확정 기록(final record) | 교사가 주간 초안을 검토·수정 후 확정한 관찰기록 |

## 8. 성공 기준 (1차 시연)

- 클래스·유아 등록 후 **1~2주 매일 업로드·자동 누적** → 수집 현황 확인 → **주간 초안 확정** → 리포트 전 흐름이 끊김 없이 시연됨.
- 관찰 후보가 누리 영역·KICCE 문항 후보·**대표 근거 클립**과 함께 제시됨.
- 얼굴 매칭이 **후보**로 제시되고 교사가 확정함(자동 확정 없음, 동의 기반).
- 교사가 **매일 검토하지 않고** 수집 현황만 확인하며, 주기적으로 초안을 확정할 수 있음.
- AI가 어떤 기록도 자동 확정하지 않으며, 점수·발달·평정을 산출하지 않음이 확인됨.
