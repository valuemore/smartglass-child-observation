# 07. UI 흐름 (Streamlit)

> 1차 UI는 Streamlit. `app/`은 화면·입력·표시만 담당하고 도메인 로직은 `services/`에 둔다.
> 화면 텍스트는 한국어.

## 1. 화면 구성

```
Home (4단계 흐름 가이드 + 우리반 현황 요약 + Safe AI 패널)
├─ 0_우리반_설정      클래스·유아 등록, 얼굴매칭 동의 토글(기본 OFF)
├─ 1_일일_영상_기록   영상 업로드 → 업로드 진행률·분석 상태·재시도 (자동 분석)
├─ 2_수집_균형        유아×누리영역 매트릭스 + 부족 영역 보완 안내
├─ 3_주간_관찰초안    기간·대상 선택 → 초안 + 대표 근거 클립 → 검토·확정
└─ 4_연구자_리포트    영역 분포·문항 커버리지·AI 지원도 지표·export(미디어 제외)
(공통 사이드바) Safe AI 패널 + AI비서(검색·초안수정·촬영제안 제한형)
```

## 2. 전체 사용자 흐름

```
[교사] 0. 우리반 설정 (클래스·유아 등록, 얼굴매칭 동의 — 기본 OFF)
          │
          ▼
[교사] 1. 매일 영상 업로드 ─▶ (업로드 즉시 자동) 전처리·클립·AI·매칭후보·누리/KICCE 후보 누적
          │   진행률·분석 상태·실패 시 재시도        ※ 매일 개별 후보 검토하지 않음
          ▼
[교사] 2. 수집 균형 확인 (수시) — 유아×누리영역 매트릭스, 부족 영역 보완 촬영
          │
          ▼
[교사] 3. 주간/격주 관찰 초안 (1~2주 주기 수동 생성)
   1) 기간(1주/2주)·대상(유아/영역) 선택 → 초안 생성
   2) 초안별 대표 근거 클립 1~3개 우선 재생 + 누리/KICCE 후보 + 얼굴 매칭 후보 확정
   3) 채택 / 수정 / 기각
   4) 확정 → final_record(주차 메타) 저장
          │
          ▼
[연구자] 4. 리포트 열람 / export (지원도 지표, 미디어 경로 제외)
```

## 3. 화면별 상세

### Home
- 상단 **4단계 흐름 스텝퍼**: `우리반 설정 → 일일 영상 기록 → 수집 균형 → 주간 초안`. 우리반 미설정 시 0번으로 유도.
- 우리반 현황 요약(등록 유아 수, 최근 업로드일, 수집 부족 영역 알림).
- **Safe AI 요약 배너**: "AI는 후보·초안만, 확정은 교사 / 점수·발달·평정 없음 / 원본·얼굴 데이터 외부 미전송 / 접근·삭제 기록".

### 0_우리반_설정 (신규)
- 클래스 생성, 유아 **가명 등록**(표시 라벨). **실명 입력란 없음**.
- 유아별 **얼굴 참조사진 업로드** + **얼굴매칭 동의 토글(기본 OFF)**. 동의 ON 시에만 참조사진·임베딩 저장, OFF·철회 시 즉시 삭제 안내.
- 동의 상태·매칭 ON/OFF를 명확히 표시.

### 1_일일_영상_기록
- 클래스·`촬영일` 선택 후 영상 업로드(제한 디렉토리 저장, 메타 추출).
- 업로드 **진행률 바** + 단계별 **분석 상태**(대기→전처리→클립→AI→누적) + 실패 시 **재시도** 버튼.
- 업로드 즉시 **자동 분석**(검토 게이트 없음). 결과 요약: 장면/클립 수, 생성된 후보 수, 누적 반영.
- "매일 개별 후보를 검토하지 않습니다 — 수집 균형에서 현황을 확인하세요" 안내.

### 2_수집_균형 (신규)
- **유아(행) × 누리 5영역(열) 매트릭스 히트맵**: 후보 수·최근 관찰일.
- 부족 셀 하이라이트 + 보완 안내 카드(예: "○○ 유아의 자연탐구 자료 부족 → 다음 촬영 보완").

### 3_주간_관찰초안 (핵심 화면)
- 기간(**1주/2주**)·대상(유아/영역) 선택 → **주간 초안 생성**.
- 초안 카드 상단에 **대표 근거 클립 1~3개**(신뢰도·길이순) 우선 재생.
- **얼굴 매칭 후보 확정 패널**: `child_A` → [등록 유아 후보 ▼ (신뢰도)] 확정/기각(동의 ON 시).
- 누리 영역 후보(칩) / KICCE 문항 후보(접이식) / 신뢰도 게이지.
- 액션: **채택 / 수정(자유 편집) / 기각** → **확정 저장**(`final_record`, 주차 메타).

```
┌──────────────── 3_주간_관찰초안 ────────────────┐
│ 기간 [2주 ▼]   대상 [가명ID p_07 ▼]   [초안 생성] │
│ ─────────────────────────────────────────────── │
│ ┌ 초안 (p_07 · 자연탐구 · 6/1~6/14) ───────────┐ │
│ │ [▶클립1][▶클립2][▶클립3]  대표 근거 클립      │ │
│ │ 얼굴매칭: child_A → [p_07 (0.61) ▼] [확정]    │ │
│ │ 초안: 블록 구조의 균형을 반복 탐색하며…        │ │
│ │ 누리: [자연탐구]   KICCE 후보 ▸ 34번 …         │ │
│ │ [채택] [수정] [기각]                          │ │
│ └─────────────────────────────────────────────┘ │
│            ... 다음 초안 ...        [확정 저장]   │
└──────────────────────────────────────────────────┘
```

### 4_연구자_리포트
- 유아별(가명 ID)·**주차별** 확정 관찰기록 모음.
- 누리 5영역 분포 차트 / KICCE 문항 커버리지(후보 기준).
- **AI 지원도 지표**: 후보 채택률·수정률·기각률, 영역/문항 커버리지 기여, 신뢰도 구간별 채택률.
- Export: JSON/CSV + 발표용 요약. **미디어 경로 제외**, **점수·발달·평정 미산출** 명시.

### 공통: AI비서 (사이드바, 제한형)
- 기능 **3종으로 제한**: (a) 확정/후보 기록 **검색**, (b) 초안 문구 **수정 보조**, (c) **보완 촬영 제안**.
- 신규 후보 자동 생성·확정·점수화 불가. 모든 질의·응답은 `ai_assistant_log`에 기록.

## 4. UI 원칙

- AI 결과는 항상 **"후보" 또는 "초안"** 으로 표기. 확정은 교사 액션으로만 발생.
- 모든 후보에 시각적 근거(대표 클립)와 신뢰도를 함께 노출.
- 얼굴 매칭 확정 전에는 임시 ID(`child_A/B`)로만 표시. 얼굴 매칭은 동의 ON일 때만 노출.
- **교사는 매일 개별 후보를 검토하지 않는다**(수집 균형 확인 → 주기적 확정).
- 점수·발달·평정 표기 없음. Safe AI 패널 상시 노출.
